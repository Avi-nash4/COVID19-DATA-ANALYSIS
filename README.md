# 🦠 COVID-19 Data Analysis

## 📌 Project Overview

This project performs exploratory data analysis on COVID-19 daily global data using Python.

The project analyzes the trends of confirmed cases, deaths, recoveries, and active cases over time and presents the findings using data visualizations.

---

## 🎯 Objectives

The main objectives of this project are:

* Analyze daily COVID-19 cases
* Analyze deaths and recoveries
* Study active case trends
* Calculate important statistics
* Create visualizations for better understanding
* Identify trends in the COVID-19 pandemic

---

## 📊 Dataset

The project uses the **COVID-19 `day_wise.csv` dataset**.

The dataset contains daily global COVID-19 statistics.

### Main Columns

* `Date`
* `Confirmed`
* `Deaths`
* `Recovered`
* `Active`
* `New cases`
* `New deaths`
* `New recovered`
* `Deaths / 100 Cases`
* `Recovered / 100 Cases`
* `Deaths / 100 Recovered`
* `No. of countries`

---

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* NumPy

---

## 🔍 Data Analysis

The project performs the following analysis:

1. Loads the COVID-19 dataset using Pandas.
2. Converts the `Date` column into datetime format.
3. Sorts the data by date.
4. Analyzes confirmed cases.
5. Analyzes deaths and recoveries.
6. Analyzes active cases.
7. Calculates daily changes.
8. Creates graphs to visualize COVID-19 trends.

---

## 📈 Visualizations

The project includes visualizations such as:

* Confirmed Cases Over Time
* Deaths Over Time
* Recovered Cases Over Time
* Active Cases Over Time
* Daily New Cases
* Daily New Deaths
* Daily New Recoveries
